# Wpf.Effects - Changelog


## 11.0.0 (2026-11-11)

Improvements:
- Added support for **`.NET 11.0`**.

Breaking Changes:
- Removed support for **`.NET 9.0`** and **`.NET 8.0`**.


## 10.0.0 (2026-02-24)

Improvements:
- Added support for **`.NET 10.0`**.


## 9.0.0 (2024-11-14)

Improvements:
- Added support for **`.NET 9.0`**.

Breaking Changes:
- Removed support for **`.NET 7.0`** and **`.NET 6.0`**.
- Replaced **`IndexRange`** with **`Microsoft.Bcl.Memory`**.


## 8.0.0 (2023-11-16)

Improvements:
- Added support for **`.NET 8.0`**, **`.NET 7.0`**, and **`.NET 6.0`**.
